# Browser AI Agent

Автономный AI-агент для управления браузером. Принимает произвольную задачу на естественном языке и выполняет её через реальный браузер Chrome.

## Возможности

- Подключается к запущенному Chrome — поддерживает постоянные сессии (можно войти на сайт вручную)
- Работает в видимом режиме (не headless)
- Управляет контекстом: не передаёт лишний HTML в модель
- Запрашивает подтверждение перед любым необратимым действием (удаление, оплата и т.д.)

## Требования

- Python 3.11+
- Google Chrome
- API key от Anthropic

## Установка

**1. Клонировать репозиторий:**

```bash
git clone https://github.com/sheeeeeri/browser_use_agent.git
cd browser_use_agent
```

**2. Создать виртуальное окружение и установить зависимости:**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**3. Настроить переменные окружения:**

```bash
copy .env.example .env
```

Открой `.env` и вставь свой ключ от Anthropic:

```
ANTHROPIC_API_KEY=your_api_key_here
```

## Запуск

**1.** Запусти `start_chrome_debug.bat` — скрипт закроет все открытые окна Chrome и перезапустит браузер в режиме отладки.

> Если задача требует авторизации — войди на нужный сайт вручную после запуска Chrome.

**2.** Запусти агента:

```bash
python main.py
```

**3.** Введи задачу на естественном языке, например:

```
Прочитай последние 10 писем в почте mail.ru и удали спам
```

## Переменные окружения

| Переменная          | Описание                              |
